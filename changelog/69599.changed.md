``pillar_mask_output`` is now a feature flag that defaults to ``False``: ``pillar.get``, ``pillar.item``, ``pillar.items`` and ``pillar.ext`` return real values and ``unmask`` has no effect. Set ``pillar_mask_output: True`` to mask them by default, and pass ``unmask=True`` to unmask a single call. ``no_log`` state output stays masked.
